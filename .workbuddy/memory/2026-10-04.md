## 本会话踩过的关键坑（后续会话必读）
- **Task 不自动展开**：TS `Promise<T>` 自动展平，C# `Task<Task<T>>` 不展平 → "同步/异步可选回调"必须统一为单一 `Func<...,Task<T>>` 签名，否则重载解析把 T 推断成 Task<object> 导致异常/取消被吞。
- **嵌套 record 坑**：位置参数名不能与 record 类型名同名（SpanStatus.Error(Error?) 与拷贝构造器二义）；record positional `{get;init;}` 不能 override 基类 `{get;}` 抽象属性；private 主构造器子类不可访问 → `private protected`。
- **TS undefined → null**：CBOR map 编码要在写 count 前过滤 null 值条目。
- **JS Proxy 不可读对象**：C# 用抛异常的派生类（override GetEnumerator / Copy）模拟，Copy/Merge 必须走公开枚举才能命中模拟。
- **JS Number 是 double**：C# 用 long + safe-integer（±2^53-1）检查保持线上兼容；整数值 double 超范围时 decode 拒绝（与 TS 一致）。
- **xunit v3**：项目需 `OutputType Exe` + `UseMicrosoftTestingPlatformRunner`，不要钉 Microsoft.Testing.Platform 版本；`dotnet test` 输出在此环境不可见，用 `dotnet exec <dll>` + iconv GBK→UTF-8 看结果。
- 深比较：Dictionary/record 嵌套成员是引用相等，用 JSON 规范化序列化比较替代 deepStrictEqual。
